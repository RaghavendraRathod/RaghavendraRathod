## 🚀 Featured Projects

### ⚙️ FlowForge — Workflow Automation & Job Execution Platform

A backend platform built with Java and Spring Boot for managing workflows and executing jobs through a task-handler architecture.

**Highlights**
- REST APIs for workflow and job management
- DEMO and ECHO task handlers
- PostgreSQL persistence for workflows and job execution results
- Job failure and retry handling
- Health monitoring with Spring Boot Actuator
- Docker-based deployment on Render with Neon PostgreSQL
- 37 automated tests passing

### 🔎 ScoutAI — AI-Powered Opportunity Discovery

An AI-powered platform that helps students and developers discover relevant internships and career opportunities using natural-language queries, profile information, live web search, and AI-powered ranking.

**Highlights**
- Natural-language opportunity search
- Personalized opportunity ranking using Google Gemini
- Live web search integration through SerpApi
- React and TypeScript frontend with a Node.js and Express backend
